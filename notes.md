# Information

**Contenu**

- L'information est un contenu qu'on peut nommer et réutiliser.
- Il prend des formes courantes : une quantité, un symbole, une date, un choix entre deux réponses.

**Exemples**

- `42` — une quantité
- `A` — un symbole
- `2026-11-10` — une date
- `oui` / `non` — un choix

**Propriétés**

- On peut le recopier sans le déformer.
- On peut le modifier selon une règle.
- On peut le conserver ou l'envoyer d'une machine à une autre.

Ce contenu traité automatiquement s'appelle l'information automatique : l'informatique. Section suivante.

# Machine

Une machine est un ordinateur. Quatre composants la constituent.

- **CPU.** *Central Processing Unit*, le processeur. Il exécute les opérations.

- **RAM.** *Random Access Memory*, la mémoire vive. Elle retient ce sur quoi les opérations portent pendant que le courant passe. Sans courant, ce contenu disparaît.

- **Disque.** Il conserve, après l'arrêt de la machine, ce que la RAM perd.

- **Réseau.** Il relie une machine à une autre.

À travers le réseau, la machine qui contacte est le client. La machine qui reste disponible et qui répond est le serveur.
